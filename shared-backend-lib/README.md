# Backend Core Library — chưa tách

Thư mục này sẽ chứa các hàm dùng chung cho toàn bộ 20 sản phẩm (CRUD helper, sinh ID, xử lý JSON response, xử lý lỗi...).

**Chưa tạo vì:** cần build xong SP-001 trước để biết chính xác những hàm nào thực sự dùng chung, thay vì đoán trước.

**Nguồn để tách:** các hàm đánh dấu `// SHARED` trong `products/SP-001-quanlyphong/Code.gs` sau khi Antigravity build xong — xem `ANTIGRAVITY_BUILD_BRIEF_SP-001.md`.
