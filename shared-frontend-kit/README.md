# Frontend UI Kit — chưa tách

Thư mục này sẽ chứa layout, form, table, style dùng chung cho toàn bộ 20 sản phẩm.

**Chưa tạo vì:** cần build xong SP-001 trước để biết chính xác những component nào thực sự dùng chung.

**Nguồn để tách:** các phần đánh dấu `// SHARED` trong `products/SP-001-quanlyphong/index.html` sau khi Antigravity build xong — xem `ANTIGRAVITY_BUILD_BRIEF_SP-001.md`.
